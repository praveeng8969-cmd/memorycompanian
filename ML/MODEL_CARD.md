# Demonstration model card

Task: recommend advance, maintain, simplify or pause from synthetic matching-session measures. This is a small Random Forest classifier, not an LLM.

Training: 960 sessions from 120 entirely simulated participants. Seed 42. Labels are generated by Backend.policy.action. An 80/20 participant split yields 768 training sessions and 192 test sessions, with no shared participant IDs. Preprocessing and classifier are saved in a single pipeline. Participant ID is excluded from the features. All activity values are matching; regional languages and other games are not modelled.

Inputs: activity, level, accuracy, hint_rate and paused. Accuracy and hint rate are fractions from 0 to 1; repeated hints are capped at 1. Zero-attempt sessions bypass ML. Model predictions are only made with at least 3 attempts. Runtime inputs are validated by the backend.

Evaluation: see artifacts/evaluation.json for this exact run's actual score, class metrics, confusion matrix and versions. High synthetic accuracy is expected from deterministic labels. It says nothing about diagnosis, clinical outcomes, fatigue detection or real-world benefits. This model imitates a simple hand-written policy; it does not discover a clinically validated personalisation strategy.

Runtime: the backend loads the trusted Joblib pipeline once at startup. The caregiver sees the ML prediction alongside the transparent policy result. The model never automatically changes difficulty, overrides pause, schedules treatment or changes reminder content. Restart the server after retraining.

Limitations: fabricated data, limited feature set, no human participants, no clinical labels, no external validation or subgroup evaluation, no regional language comparison. Use only in a supervised academic demonstration. Collecting real data would require a separately designed consent, privacy and evaluation process.

The saved model was trained using scikit-learn 1.8.0. For portability, install requirements and retrain locally rather than relying on cross-version serialization.
